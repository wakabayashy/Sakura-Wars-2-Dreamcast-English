# Sakura Wars 2 — Dreamcast English Translation

An English translation and editing project for **Sakura Wars 2: Thou Shalt Not Die (Sakura Taisen 2)** on the **Sega Dreamcast**.

> **Current status: Translation and editing in progress.**

## About the Project

This project aims to make the Dreamcast version of Sakura Wars 2 accessible to English-speaking players through an English fan translation.

The work is currently focused on translating and editing the game's content. The project is still in development; no completion percentage or public release date is being announced at this stage.

## Current Progress

- **Platform:** Sega Dreamcast
- **Language:** English
- **Translation:** In progress
- **Text editing:** In progress
- **Current status:** Active development
- **Public Beta:** Not announced
- **Public release:** To be announced

## Work and Quality Goals

The project aims to provide a readable and consistent English experience while preserving the original game's presentation and progression.

As the work advances, this repository will be updated with confirmed information about translated content, technical integration, testing builds and release notes.

## Testing and Feedback

A public Beta has not been announced yet. When a testing phase is ready, information about access and feedback will be shared through the team Discord.

Useful reports should include:

1. The scene, chapter, menu or event where the issue appears.
2. A screenshot when possible.
3. What happened and what was expected.
